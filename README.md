# Oxygen-Frame

**Oxygen-Frame** is an open-source, lightweight Windows 11 tool that lets you create a customizable floating image popup window on your desktop. Perfect for keeping inspirational quotes, reference designs, mood boards, or a photo slideshow pinned on your screen while you work.

## ✨ Features

* **Fully Resizable & Draggable:** Scale and place your image frame anywhere on your desktop effortlessly.
* **Single Image or Slideshow:** Choose to lock down a single permanent image or cycle through a gallery.
* **Custom Time Intervals:** Take full control over how frequently slideshow images transition.
* **Clean & Modern UI:** Designed to look completely native and minimalist on Windows 11.
* **100% Open Source:** Light on resources, tracking-free, and fully open for community contributions.

## 🚀 Getting Started

### Prerequisites
* Windows 11 / Windows 10
* .NET Runtime (or insert specific language dependencies here if required, e.g., Python, C#)

### How to Use
1. Download the latest release or clone the repository.
2. Run `Oxygen-Frame.exe` (or your startup script).
3. Right-click the frame or open the settings panel to select your images folder.
4. Adjust your transition times, choose your layout size, and position it wherever fits your workflow.
